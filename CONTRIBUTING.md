# Contributing to Open Source Software

Thank you for considering contributing to this Open Source Software.

Please note that we welcome all forms of user feedback and are generally open
to many forms of collaboration,
but please read this document carefully before proceeding.

## Contributing to the development

External contributions can be accepted, if they provide appropriate
functionality and are of acceptable quality.
Specific requirements and criteria may apply to specific tools.

### Practical matters

I reserve the right to accept or reject any contribution.
